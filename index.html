🔧 Fix Your Git Setup

DevOps Ready You're facing 3 common issues: empty folder, branch mismatch (`master` → `main`), and GitHub auth. Here’s the exact fix:

Step 1: Create & Save Your First File 
touch index.html
# OR use nano/vim:
nano index.html
# Paste HTML, then Ctrl+O → Enter → Ctrl+X
Step 2: Stage, Commit & Rename Branch 
git add .
git commit -m "First deployment file"

# Rename local branch to 'main' (GitHub default)
git branch -M main
Step 3: Push with Modern Auth (PAT or SSH) 
# Replace YOUR_TOKEN with your GitHub Personal Access Token
git remote add origin https://@github.com/username/repo.git
git push -u origin main

# 💡 Pro Tip: Use SSH for passwordless pushes
# ssh-keygen -t ed25519 -C "your_email@example.com"
# Add public key to GitHub Settings → SSH Keys
